# 内置浏览器扩展方案

共享盘版 Maxwell 携带一份已经通过 Chrome 正式安装 OpenRPA 扩展的干净 Chrome++ 配置。扩展 ID 为：

```text
hpnihnhlcnfejboocnckgchjdofeaphe
```

运行浏览器工作流时，Maxwell 会在当前 Windows 用户下分别准备：

```text
%LOCALAPPDATA%\Maxwell\BundledChrome
%LOCALAPPDATA%\Maxwell\BrowserProfile
%LOCALAPPDATA%\Maxwell\NativeMessagingHost
```

- `BundledChrome` 是从共享盘复制到本机的内置浏览器程序，避免 Chrome 从 UNC/SMB 路径启动时闪退。
- `BrowserProfile` 首次从发布包的干净 `Data` 配置初始化，其中已经登记 OpenRPA 扩展。旧版 Maxwell 创建的配置如果缺少该扩展，会被自动替换。
- `NativeMessagingHost` 在本机注册为 `com.openrpa.msg`，允许上述扩展 ID 连接。RuntimeHost 不会再把注册表路径改回共享盘。

Maxwell 不再使用 `--load-extension` 或 `--disable-extensions-except`。新版正式 Chrome 已经忽略这些命令行安装方式，因此发布包也不再携带旧的 `runtime\browser-extension` 目录。

如果更新配置时提示文件被占用，需要先关闭所有由 Maxwell 打开的 Chrome 窗口和残留 `chrome.exe` 进程，再重新执行工作流。
