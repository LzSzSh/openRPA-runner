# 本机浏览器版：首次启用浏览器自动化

`Maxwell-version4-local-browser.zip` 不包含内置 Chrome，浏览器 workflow 会使用员工本机的 Chrome。

首次使用浏览器自动化前，在解压后的 Maxwell 顶层目录运行：

```powershell
.\install-openrpa-extension.ps1
```

该脚本会：

1. 为当前 Windows 用户注册 Maxwell 的 Native Messaging Host；
2. 打开 Chrome 网上应用店中的官方 OpenRPA 扩展页面；
3. 用户在 Chrome 中确认一次“添加至 Chrome”。

扩展 ID 是 `hpnihnhlcnfejboocnckgchjdofeaphe`。安装成功后，关闭所有 Chrome 窗口并重新打开，再运行 Maxwell workflow。

Maxwell 每次运行时也会自动更新当前用户本机的 Native Messaging Host；脚本只用于首次安装浏览器扩展或手动修复。
