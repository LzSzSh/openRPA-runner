# 公司共享工作流目录（本地试用说明）

在 Maxwell 的“设置”页面填写共享根目录，例如：

```text
\\server\RPA\PublishedProjects
```

Maxwell 会在启动时读取一次；修改共享目录路径时只会保存设置，设计人员新增或更新工作流后，用户可点击“立即刷新”重新读取。刷新后仍停留在设置页。列表和执行都直接使用网络共享路径，不创建本地缓存。

## 发布人员目录约定

共享根目录下的每个直接子文件夹是一个项目。项目必须放入完整运行资源：workflow JSON、依赖 JSON、图片、脚本及运行所需的其他文件都要保持原有相对目录结构。

```text
\\server\RPA\PublishedProjects
└── project1
    ├── project1.rpaproj
    ├── workflows
    │   └── Main.json
    ├── assets
    │   └── example.png
```

不需要创建 `maxwell-publish.json` 或其他发布标记。Maxwell 会直接递归扫描该目录内符合 OpenRPA workflow 格式的 JSON 文件。

## 运行与更新规则

- 用户运行的是共享盘上的项目资源；设计人员更新文件后，客户端下次刷新即可看到新内容。
- 运行中的 workflow 不会自动刷新列表；结束后可由用户手动点击“立即刷新”。
- 网络中断、权限不足或共享文件被占用时，Maxwell 会在“设置”页和日志中提示，用户需要恢复网络或共享权限后重试。
- 因为直接运行网络路径，设计人员不应在用户可能执行时覆盖同一项目。建议先在其他文件夹完成设计和验证，再整体移动到共享目录，或选择业务低峰时更新。
- 当 Maxwell 和内置浏览器位于共享盘时，首次执行浏览器 workflow 会自动将 Maxwell 自带的 Chrome 复制到当前用户的本机专用目录后启动；这不是使用用户自行安装的 Chrome，也不复制 workflow 项目。
